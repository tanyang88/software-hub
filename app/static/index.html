忘记密码

本站密码保存在服务器本地。请在服务器上执行下面的命令重置密码：

docker compose exec software-hub python app/reset_password.py
# 或指定新密码：
docker compose exec -e RESET_PASSWORD=新密码 software-hub python app/reset_password.py

不填新密码时，默认重置为 admin123，重置后请尽快在「设置 → 账号安全」里修改。
